Sift for GitHub

Tabs for GitHub pull request files

Tabs

One pattern per line, in gitignore syntax (case-insensitive). Rules apply top to bottom; a later line overrides an earlier one. *.md matches a name at any depth, docs/*.md or /build is relative to the repo root, test/ matches every file under a test folder, ** spans folders, # starts a comment. Exclude with !: !*.md drops files matching that pattern, !Manifest drops files the Manifest tab would hold. A tab whose first line is a ! starts from every file. Two tabs can exclude each other; a file both would hold then shows in neither.

Try a path

See which tabs a file lands in with the rules above, before saving.

Behavior

The tab you pick on a PR is remembered for that PR across refreshes. This only applies to PRs you open fresh.

Tabs that hold no files in the open PR are left out of the tab bar. All and the tab you're on always show.

Experiments

When a PR opens on a tab other than All, fetch every diff in that tab first, in large batches, instead of GitHub's one request at a time through the whole PR (new Files changed page).

Then fetch every other diff in the PR, so switching tabs is instant and makes no requests. With this off, only the open tab loads and other tabs load when you open them; GitHub's large-PR list is used for that, so Find on Page only sees diffs near the screen. The classic page always loads every diff, as GitHub does.

Fetch diffs several requests at a time instead of GitHub's one after another: large batches are split into parallel requests, and GitHub's own small ones are fetched ahead.

All experiments are on by default and take effect on the next page load.
